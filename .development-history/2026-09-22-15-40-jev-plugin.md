# Build the jev Claude Code plugin

## Summary

Built a Claude Code plugin that routes skill selection and post-turn judgment through TypeSafe
Jev on OpenRouter's alpha Decisions API, and prepared it for public release.

## Changes

- `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`: manifest and single-repo marketplace
- `hooks/hooks.json`: SessionStart, UserPromptSubmit, and Stop hooks in exec form
- `scripts/lib/`: config, hook I/O, Decisions client, frontmatter parser, catalog discovery, question builders, formatting, transcript slicing
- `scripts/hooks/route.mjs`: stateless chunk tournament over the installed catalog
- `scripts/hooks/judge.mjs`: post-turn judgment parked on disk for the next prompt
- `scripts/cli.mjs`: `decide`, `route`, `judge`, `catalog`, `doctor`, and the three hook entry points
- `skills/`: `ask`, `route`, `judge`, `doctor`
- `tests/`: 53 tests including four that run the hooks against a mock Decisions server

## Decisions

- Jev answers typed questions, so "judge the code" became six narrow questions rather than a review request.
- The Stop hook writes to disk instead of stdout: Claude Code ignores `systemMessage` and `additionalContext` on Stop.
- Routing is a stateless tournament, not a cached domain taxonomy: a choice caps at 255 options and the local catalog holds 537.
- Turns are sliced by the index of the user entry carrying `promptId`, because assistant entries carry none.
- Hooks end without a bare `process.exit()`, which aborts the process on Windows while a socket is closing.

## Verification

- `npm test`: 53 passed, 0 failed
- `claude plugin validate . --strict`: Validation passed
- Route and Stop hooks with no API key: exit 0, empty stdout
- `node scripts/cli.mjs catalog`: 537 entries discovered in ~110 ms

## Limitations

- No live call to the real Decisions API yet: no `OPENROUTER_API_KEY` is set on this machine.
- Routing accuracy over 200-option chunks is untested against the live model.
- Plugins loaded with `--plugin-dir` are absent from the registry, so `JEV_EXTRA_PLUGIN_DIRS` must name them.
